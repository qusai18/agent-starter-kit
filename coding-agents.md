# Ways to get a coding agent

Prices and quotas change fast. Check the plan pages before you pay.
(Snapshot from the Coding Agent Setup Kit by Alexey Grigorev.)

## Free

- **OpenCode Zen** - several free models inside OpenCode. "Contributor" tiers
  may use your data for training. Roughly one or two heavy sessions.
- **OpenRouter** - model IDs ending in `:free` cost nothing; strict rate limits
  until you add credit.

## Cheap ($8-20/month)

- **OpenCode Go** ($10) - with Zen, several hours of work a day
- ChatGPT Plus ($20), Z.ai GLM Coding Plan Lite, MiniMax Token Plan, Command Code
- **Pay per call** - direct API spend goes fast; cheaper models off-peak stretch it

## Subscriptions

- **ChatGPT Plus** ($20) - includes Codex
- **Claude Pro** ($20) - includes Claude Code; heavy use needs Max ($100)
- **GitHub Copilot** - token-based billing now
- **Cursor** - reads `AGENTS.md` at the repo root, so this kit works there too

## How to start

1. A paid Codex or Claude subscription if you can.
2. Otherwise free models in OpenCode Zen, then OpenCode Go when you hit limits.
